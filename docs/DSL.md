# 对拍输入 DSL 语法

指令式语言，描述内置生成器的输入格式。语句顺序执行，可引用前面定义的名字。

## 结构：行块 + 顶层命令

```
行 (3):                              # 行块（可选重复次数，表达式）
    整数 n: 1, 100                    # 行内子项：类型 名字: 参数
    浮点 x: 0, 1, 4
    文本 s: "---"
    表达式 e: 2 * n
    字符串 c: 10, "ab"
a = ints(3, 1, 9)                    # 顶层命令（与行同级）
t = tree(n, w=int(1, 10))
```

- **行**（`行:` + 缩进子项）等级高于整数/浮点/文本/表达式/字符串——这些标量类型
  **必须**放在行块内，顶层写会报错引导
- 顶层命令：`ints` `floats` `matrix` `matf` `perm` `binseq` `intervals` `points`
  `tree` `graph` `ring` `base_ring`（`name = 命令(...)`）
- 已废弃：`int` `float` `str` `strs` 顶层写法（改为行内项；`strs` 用行重复替代）

## 行内项（类型 名字: 参数）

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 整数 | `整数 n: 1, 100` | 随机整数 [min, max] |
| 浮点 | `浮点 x: 0, 1, 4` | 随机浮点（精度可省，默认 6） |
| 表达式 | `表达式 e: 2 * n` | 任意标量表达式（引用/int()/float()/算术/数组索引） |
| 文本 | `文本 s: "---"` | 固定字面量，逐行输出，不可引用 |
| 字符串 | `字符串 c: 10, "ab"` | 随机字符串（长度可为表达式，如 `int(3,5)` 区间随机；字符集可省） |

- 行内项顺序执行，同一行内后者可引用前者（取当前行值）
- 数值项（整数/浮点/表达式）可被后续语句引用

## 行重复

```
行 (3):                              # 重复 3 行，每行独立随机
    整数 n: 1, 100
    表达式 m: 2 * n
行:
    表达式 x: n[2]                    # 取第 2 行的 n（1 起）
```

- 重复时行内数值项**数组化**（长度 = 行数），引用必须 `n[k]`；标量引用报错
- 行数可以是表达式（引用前面变量）
- 文本/字符串项逐行输出，不参与数组化

## 表达式（任何数值位置都可写）

```
常数        5、1.5
引用        前面变量的名字，如 n（取该变量本次生成的值）
数组索引    单行数组 a[2]、矩阵 M[i][j]（1 起；越界报错）
表达式      2*n、n+1、n//2、n % 3、2 ** k
范围随机    int(1,5)、float(0,1,4)（min~max 随机取一个）
```

运算符：`+ - * / // % **`，支持括号与一元负号。`//` 整除，`%` 取模（与 Python 语义一致）。

## 顶层命令一览

| 命令 | 示例 | 输出 |
| --- | --- | --- |
| `ints` | `a = ints(n, 1, 100)` | 一行 n 个整数 |
| `floats` | `b = floats(3, 0, 1, 5)` | 一行 3 个浮点 |
| `matrix` | `M = matrix(3, n, 0, 1)` | rows × cols 整数矩阵 |
| `matf` | `F = matf(int(1,5), n, 0, 1, 4)` | rows × cols 浮点矩阵 |
| `perm` | `p = perm(n)` | 一行 1..n 随机排列 |
| `binseq` | `z = binseq(n, 3)` | 一行 0/1 序列（恰好 3 个 1） |
| `intervals` | `iv = intervals(n, 1, 100)` | n 行 `l r`（l ≤ r） |
| `points` | `pt = points(n, 1, 10, 1, 10)` | n 行 `x y` |
| `tree` | `t = tree(n, w=int(1,10), val=int(1,9))` | n + n-1 条边（可选边权/节点权） |
| `graph` | `g = graph(n, m, 1, 0, w=int(1,10))` | n m + m 条边（有向/连通/边权可选） |
| `graph` | `g = graph(n, m, 1, 0, type="dag")` | 有向无环图 |
| `graph` | `g = graph(n, m, 0, 0, type="bipartite")` | 二分图 |
| `ring` | `r = ring(n, w=int(1,10))` | 环：n 条边首尾相连 |
| `base_ring` | `br = base_ring(n, 3, w=int(1,10))` | 基环树：n 顶点，环大小 k |

图命令参数：`graph(n, m, directed, connected[, type=…][, w=…][, val=…])`，
`directed`/`connected` 用 1/0（或 true/false）。权值：`w=int(1, 10)` /
`w=float(0, 1, 4)` / `val=int(1, 9)` / `w=none`。

## 引用规则

- 只能引用**前面**定义的名字
- 数组/区间/点集等**不可整体作为引用源**（数组可用 `a[i]` 索引引用元素）
- `perm`/`tree`/`graph`/`ring`/`base_ring` 被引用时取其**规模值**（n）
- 重复行的数值项须用 `n[k]` 索引引用
- 变量名：字母/下划线开头，仅含字母/数字/下划线；不能是保留字（命令名、
  行/整数/浮点/文本/表达式/字符串、`repeat` 等）；不能重复

## 多测模式

顶部注释开启（前 8 行内识别）：

```dsl
# 多测模式：重复 3 次
行:
    整数 n: 1, 100
a = ints(n, 1, 100)
```

生成时首行输出组数 N，随后整块语句独立随机重复 N 次（每轮只可引用当轮前面的值）。

## 校验

解析与静态校验（实时提示，不阻断）：语法、变量名/保留字/重复、定义顺序、
引用规则、常量值域（如 `整数 n: 5, 4`、`graph(3, 10, 0, 0)` 边数超上限）、
数组索引层数与常量越界。含变量引用的范围在生成期动态检查。
