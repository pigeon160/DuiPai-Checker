# 对拍输入 DSL 语法

指令式语言，描述内置生成器的输入格式。语句顺序执行，可引用前面定义的名字。
语法为英文关键字；错误提示为中文。

## 结构：行块 + 顶层命令

```
line (3):                              # 行块（可选重复次数，表达式）
    int n: 1, 100                      # 行内子项：类型 名字: 参数
    float x: 0, 1, 4
    text s: "---"
    expr e: 2 * n
    str c: 10, "ab"
a = ints(3, 1, 9)                      # 顶层命令（与行同级）
t = tree(n, int(1, 10))
```

- **行**（`line:` + 缩进子项）等级高于 int/float/text/expr/str——这些标量类型
  **必须**放在行块内，顶层写会报错引导
- 顶层命令：`ints` `floats` `matrix` `matf` `perm` `binseq` `intervals` `points`
  `tree` `graph` `ring` `base_ring`（`name = 命令(...)`）
- 已废弃写法见文末「已废弃」一节

## 行内项（类型 名字: 参数）

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| int | `int n: 1, 100` | 随机整数 [min, max] |
| float | `float x: 0, 1, 4` | 随机浮点（精度可省，默认 6） |
| expr | `expr e: 2 * n` | 任意标量表达式（引用/int()/float()/算术/数组索引） |
| text | `text s: "---"` | 固定字面量，逐行输出，不可引用 |
| str | `str c: 10, "ab"` | 随机字符串（长度可为表达式，如 `int(3,5)` 区间随机；字符集可省） |

- 行内项顺序执行，同一行内后者可引用前者（取当前行值）
- 数值项（int/float/expr）可被后续语句引用

## 行重复

```
line (3):                              # 重复 3 行，每行独立随机
    int n: 1, 100
    expr m: 2 * n
line:
    expr x: n[2]                       # 取第 2 行的 n（1 起）
```

- 重复时行内数值项**数组化**（长度 = 行数），引用必须 `n[k]`；标量引用报错
- 行数可以是表达式（引用前面变量）
- text/str 项逐行输出，不参与数组化

## 表达式（任何数值位置都可写）

```
常数        5、1.5
引用        前面变量的名字，如 n（取该变量本次生成的值）
数组索引    单行数组 a[2]、矩阵 M[i][j]（1 起；越界报错）
表达式      2*n、n+1、n//2、n % 3、2 ** k
范围随机    int(1,5)、float(0,1,4)（min~max 随机取一个）
```

运算符：`+ - * / // % **`，支持括号与一元负号。`//` 整除，`%` 取模（与 Python 语义一致）。

## 顶层命令一览

| 命令 | 示例 | 输出 |
| --- | --- | --- |
| `ints` | `a = ints(n, 1, 100)` | 一行 n 个整数 |
| `floats` | `b = floats(3, 0, 1, 5)` | 一行 3 个浮点 |
| `matrix` | `M = matrix(3, n, 0, 1)` | rows × cols 整数矩阵（可 `M[i][j]` 索引） |
| `matf` | `F = matf(int(1,5), n, 0, 1, 4)` | rows × cols 浮点矩阵 |
| `perm` | `p = perm(n)` | 一行 1..n 随机排列 |
| `binseq` | `z = binseq(n, 3)` | 一行 0/1 序列（恰好 3 个 1） |
| `intervals` | `iv = intervals(n, 1, 100)` | n 行 `l r`（l ≤ r） |
| `points` | `pt = points(n, 1, 10, 1, 10)` | n 行 `x y` |
| `tree` | `t = tree(n, int(1,10))` | n-1 条边（**无规模行**） |
| `tree` | `t = tree(n, type="star")` | 菊花图（中心连所有点） |
| `tree` | `t = tree(n, type="chain")` | 链（随机排列顶点连成链） |
| `graph` | `g = graph(n, m, 1, 0, int(1,10))` | m 条边（**无规模行**） |
| `graph` | `g = graph(n, m, 1, 0, type="dag")` | 有向无环图（u < v） |
| `graph` | `g = graph(n, m, 0, 0, type="bipartite")` | 二分图 |
| `ring` | `r = ring(n, int(1,10))` | 环：n 条边首尾相连 |
| `base_ring` | `br = base_ring(n, 3, int(1,10))` | 基环树：n 顶点，环大小 k |

图命令参数：`graph(n, m, directed, connected[, multi=1][, loop=1][, type=…][, 边权])`，
`directed`/`connected`/`multi`/`loop` 用 1/0（或 true/false）。
边权直接写范围调用（位置参数）：`int(1, 10)` / `float(0, 1, 4)`；写 `none` 明确表示无边权。

### 重边与自环

- `multi=1`：允许重复边，边数 m 无上限（有放回采样）
- `loop=1`：允许自环（u 可等于 v），边数上限相应放宽
- 默认（无 multi 无 loop）：完全图边数上限，超出报错

## 引用规则

- 只能引用**前面**定义的名字
- 数组/区间/点集等**不可整体作为引用源**（数组可用 `a[i]` 索引引用元素）
- `perm`/`tree`/`graph`/`ring`/`base_ring` 被引用时取其**规模值**（n）
- 重复行的数值项须用 `n[k]` 索引引用
- 变量名：字母/下划线开头，仅含字母/数字/下划线；不能是保留字（命令名、
  line/int/float/text/expr/str、repeat 等）；不能重复

## 多测模式

顶部注释开启（前 8 行内识别）：

```dsl
# 多测模式：重复 3 次
line:
    int n: 1, 100
a = ints(n, 1, 100)
```

生成时首行输出组数 N，随后整块语句独立随机重复 N 次（每轮只可引用当轮前面的值）。

## 校验

解析与静态校验（实时提示，不阻断）：语法、变量名/保留字/重复、定义顺序、
引用规则、常量值域（如 `int n: 5, 4`）、数组索引层数与常量越界、
图边数上限（含自环/重边选项）、点个数超坐标组合数、菊花图 n≥2 等。
含变量引用的范围在生成期动态检查。

## 自然语言 → DSL

第五面板「自然语言 → DSL」把输入格式的**中文/英文描述**自动转换为 DSL：
规则引擎零延迟命中常见题型（多测 / 第一行 / 接下来 N 行 / 每行 / 数组 /
矩阵 / 树 / 图 / 排列 / 区间 / 点集），未识别部分用默认值并在警告中提示。

支持的范围写法：`(1<=n<=100)`、`1 ≤ n ≤ 10^5`、`n∈[1,100]`、`n in [1, 10^9]`、
`1 到 100`、`不超过 10^9`、`int(1, 9)`；数量可用中文数字（两个/三行）或
变量（n 个 / N 行 / T 组）。

示例：

```text
输入：多测，T 组。第一行两个整数 n m，接下来 n 行每行两个整数 a b，
      然后一棵带边权的树，边权 1 到 100
输出：
# 多测模式：重复 t 次
line:
    int t: 1, 100
    int n: 1, 100
    int m: 1, 100
line (n):
    int a: 1, 100
    int b: 1, 100
t = tree(n, int(1, 100))
```

转换结果带**置信度**与**来源标签**（规则/模型），可一键载入 DSL 编辑器。
本地大模型通道（llama.cpp）规划中：放置 GGUF 模型文件后可加载推理，
未配置时由规则引擎承担转换。

## 已废弃写法

以下写法会被解析器报错拒绝（错误信息中文，指向替代写法）：

| 废弃写法 | 替代写法 |
| --- | --- |
| 顶层写 `int` / `float` / `str`（如 `n = int(1, 100)`） | 放入行块：`line:` + `int n: 1, 100` |
| 顶层写 `text` / `expr` | 同上（text/expr 均为行内项） |
| 节点权值 `val=int(1, 9)`（tree/graph 等） | 已移除（树/图只输出边） |
| 边权 `w=int(1, 9)`（tree/graph/ring/base_ring） | 位置参数：`tree(5, int(1, 9))` |
| 精度 `prec=6`（ints/floats/matrix/matf） | 位置参数：`ints(3, 1, 9, 6)` |
