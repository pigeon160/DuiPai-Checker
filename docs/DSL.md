# 对拍输入 DSL 语法

指令式语言，描述内置生成器的输入格式。每条语句一行，顺序执行，可引用前面定义的名字。

## 赋值

一行 = 顶层逗号分隔的多个 `name = expr` 赋值：

```dsl
n = int(1, 100)                  # 单赋值：整数变量，输出一行
n = 2 * m + 1                    # 标量表达式绑定：任意表达式，输出一行
n = int(1, 100), m = 2 * n       # 多赋值：一行输出多个数，每项 name = expr
```

- 单赋值右侧是命令调用（`ints`/`perm`/`tree`/`graph`…）→ 命令语义
- 单赋值右侧是 `int(a,b[,p])` / `float(a,b[,p])` 简单形式 → 整数/浮点变量
- 单赋值右侧是其他任意表达式 → 表达式变量（值可被后续引用）
- **多赋值每项必须输出单个数值**（数组/树/图等输出多行的类型不允许，会报错）
- 同一行内顺序执行，后者可引用前者

## 表达式（任何数值位置都可写）

```
常数        5、1.5
引用        前面变量的名字，如 n（取该变量本次生成的值）
数组索引    单行数组 a[2]、矩阵 M[i][j]（1 起；越界报错）
表达式      2*n、n+1、n//2、n % 3、2 ** k
范围随机    int(1,5)、float(0,1,4)（min~max 随机取一个）
```

运算符：`+ - * / // % **`，支持括号与一元负号。`//` 整除，`%` 取模（与 Python 语义一致）。

### 数组索引引用

```dsl
a = ints(3, 1, 100)          # 单行数组
m = int(1, a[2])             # 引用 a 的第 2 个元素（1 起）
M = matrix(2, 3, 0, 1)       # 矩阵
x = M[1][2]                  # 第 1 行第 2 列
```

- 单行数组用 `a[i]` 一个索引；矩阵用 `a[i][j]` 两个索引，层数不匹配报错
- 索引 1 起，越界在生成期报错；常量索引 + 常量长度可静态判定越界时提前报错
- 数组整体（未索引）不可作为引用源

## 命令一览

| 命令 | 示例 | 输出 |
| --- | --- | --- |
| `int` | `n = int(1, 100)` | 一行一个整数 |
| `float` | `x = float(0, 1, 4)` | 一行一个浮点（精度可省，默认 6） |
| `ints` | `a = ints(n, 1, 100)` | 一行 n 个整数 |
| `floats` | `b = floats(3, 0, 1, 5)` | 一行 3 个浮点 |
| `matrix` | `M = matrix(3, n, 0, 1)` | rows × cols 整数矩阵 |
| `matf` | `F = matf(int(1,5), n, 0, 1, 4)` | rows × cols 浮点矩阵 |
| `perm` | `p = perm(n)` | 一行 1..n 随机排列 |
| `str` | `s = str(10, "01")` | 一行字符串（字符集可省） |
| `strs` | `g = strs(2, n, "ab")` | 字符网格 |
| `binseq` | `z = binseq(n, 3)` | 一行 0/1 序列（恰好 3 个 1） |
| `intervals` | `iv = intervals(n, 1, 100)` | n 行 `l r`（l ≤ r） |
| `points` | `pt = points(n, 1, 10, 1, 10)` | n 行 `x y` |
| `tree` | `t = tree(n, w=int(1,10), val=int(1,9))` | n + n-1 条边（可选边权/节点权） |
| `graph` | `g = graph(n, m, 1, 0, w=int(1,10))` | n m + m 条边（有向/连通/边权可选） |
| `graph` | `g = graph(n, m, 1, 0, type="dag")` | 有向无环图 |
| `graph` | `g = graph(n, m, 0, 0, type="bipartite")` | 二分图 |
| `ring` | `r = ring(n, w=int(1,10))` | 环：n 条边首尾相连 |
| `base_ring` | `br = base_ring(n, 3, w=int(1,10))` | 基环树：n 顶点，环大小 k |

图命令参数：`graph(n, m, directed, connected[, type=…][, w=…][, val=…])`，
`directed`/`connected` 用 1/0（或 true/false）。树/图/环的权值：

```
w=int(1, 10)          # 整数边权
w=float(0, 1, 4)      # 浮点边权（精度 4）
val=int(1, 9)         # 节点权值
w=none                # 显式无
```

## 引用规则

- 只能引用**前面**定义的名字
- 数组/字符串/区间/点集等**不可整体作为引用源**（数组可用 `a[i]` 索引引用元素）
- `perm`/`tree`/`graph`/`ring`/`base_ring` 被引用时取其**规模值**（n）
- 多赋值行的每个名字都可被引用
- 变量名：字母/下划线开头，仅含字母/数字/下划线；不能是保留字（命令名、`repeat`）；不能重复

## 多测模式

顶部注释开启（前 8 行内识别）：

```dsl
# 多测模式：重复 3 次
n = int(1, 100)
a = ints(n, 1, 100)
```

生成时首行输出组数 N，随后整块语句独立随机重复 N 次（每轮只可引用当轮前面的值）。

## 校验

解析与静态校验（实时提示，不阻断）：语法、变量名/保留字/重复、定义顺序、
引用规则、常量值域（如 `int(5, 4)`、`graph(3, 10, 0, 0)` 边数超上限）。
含变量引用的范围在生成期动态检查。
