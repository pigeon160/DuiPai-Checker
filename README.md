# 竞赛对拍机（DuiPai Checker）

GitHub：[pigeon160/DuiPai-Checker](https://github.com/pigeon160/DuiPai-Checker)

图形化对拍工具：用随机数据反复运行“正解”与“暴力”两份程序并比较输出，自动找出
**WA（答案不一致）/ TLE（超时）/ RE（运行错误）** 反例，并保存现场供分析。

纯标准库实现（tkinter + subprocess + threading + random 等），跨平台：
**Linux / Windows / macOS**。Windows 下可用 PyInstaller 打包为无控制台的单文件 exe。

![风格] 朴素界面：自适应原生主题（Windows/macOS/Linux 各自原生外观）、浅色背景、默认控件。

---

## 特性

- **程序路径**
  - “运行命令”模式：如 `python3 ./sol.py`、`./sol`（已编译程序）。
  - “C++ 源码”模式：填 `.cpp` 路径（浏览自动识别），开始对拍时自动用 g++ 编译后运行；
    编译器与编译参数可配置（默认 `g++` / `-O2 -std=c++17`）。
- **数据生成器**
  - 内置：整数、浮点数、数组、排列、树、图。
    - 数组支持“行数 × 每行长度”的多行输出（如 `2*n`、`n*m`）；
    - 树/图支持边权（无/整数/浮点）、有向/无向、任意/保证连通；
    - 数组行数/每行长度、树/图的 n/m、排列长度等都可**引用前面变量的值**（浮点取整）。
  - 外置：接入一个生成程序，每次对拍运行它，把其标准输出作为测试数据；
    支持 C++ 源码自动编译；填写随机种子时以 `--seed <值>` 传递。
- **试运行**：正解/暴力各有一个“试运行”按钮——生成一份样例 → 编译 → 运行，
  在“试运行输出”区显示耗时、返回码、样例输入与标准输出。
- **源码查看**：主界面内嵌只读源码区（带行号），可查看正解/暴力/外置生成器的源码。
- **对拍参数**：组数（`-1` 无限）、超时秒数、随机种子、忽略行末空格（并忽略末尾空行）。
- **结果处理**：PASS / WA / TLE / RE；WA 或异常时把 `test.in / prog.out / std.out`
  复制到 `./fail/` 目录（`fail_<编号>.in` 等，递增不覆盖）。
- **整窗可滚 + 像素级平滑滚轮**：内容超高时出现滚动条，滚轮翻页；变量列表独立滚动；
  平滑滚轮小步长跨事件累积，无顿挫。
- **滚动链 + 区块折叠**：内层自滚动区域到边界时滚轮自动交给整窗（任意位置滚动都响应）；
  5 个主区块标题栏可点击折叠/展开，折叠状态跨会话保存（`duipai_state.json`）。

## 内置生成器变量类型

| 类型 | 输出格式 | 关键设置 |
| --- | --- | --- |
| 整数变量 | 一行一个整数 | 最小值 / 最大值（可引用） |
| 浮点数变量 | 一行一个浮点数（保留 6 位） | 最小值 / 最大值、精度（可引用） |
| 数组变量 | 多行，每行多个元素 | 元素类型（整/浮）、元素范围、行数、每行长度（各可随机或引用）、精度 |
| 排列变量 | 一行 `1..n` 的随机排列 | 长度 n（随机或引用） |
| 字符串变量 | 一行/多行字符 | 长度、行数（随机或引用）、字符集 |
| 0/1 序列 | 一行 n 位 0/1 | 长度 n、1 的个数 k |
| 区间 | n 行，每行 `l r` | 个数 n、范围 lo~hi |
| 点集 | n 行，每行 `x y` | 个数 n、x 范围、y 范围 |
| 树变量 | `n` + n-1 条边（可带权） | 顶点数 n（随机或引用）、边权（无/整/浮）、节点权值（无/整/浮） |
| 图变量 | `n m` + m 条边（可带权） | 顶点数 n、边数 m（随机或引用）、有向/无向、连通/任意、边权、结构（一般/二分图/DAG/环/基环树）、节点权值 |

> “引用前面变量”即取该变量本次生成的值（浮点取整），支持 `2*n`、`n*m`、
> “树 n + n 个权值”等常见组合。
> 多组测试数据可用 DSL 的 `group(次数):` 缩进块表达。

## 对拍输入 DSL（指令式语言）

内置生成器提供 **图形化配置** 与 **DSL 文本** 上下对照显示：上半区是图形化变量
列表，下半区是同步显示的 DSL 脚本（编辑图形化时 DSL 实时更新；也可直接编辑 DSL
后点“应用（转为图形化）”转回图形化）。DSL 作为底层格式，所有数值位置都支持
表达式：常数、引用前面变量、`2*n` 等算术、以及 `int(a,b)` / `float(a,b)` 范围随机。

```
# 每条语句一行；# 为注释；顺序执行，可引用前面定义的名字
n  = int(1, 100)            # 整数变量，随机 [1,100]，输出一行
x  = float(0, 1)            # 浮点变量（默认6位精度）
x4 = float(0, 1, 4)         # 浮点变量，精度4位
a  = ints(n, 1, 9)          # 数组：一行 n 个整数，范围 [1,9]
b  = floats(3, 0, 1)        # 数组：一行 3 个浮点
c  = ints(int(1,5), 1, 9)   # 数组：个数随机 1~5
d  = ints(2*n, 0, 1)        # 数组：个数 = 表达式
M  = matrix(2, n, 0, 1)     # 数组：2 行 × n 列整数（多行）
p  = perm(n)                # 排列：一行 1..n 的随机排列
s  = str(n, "ab")           # 字符串：一行 n 个字符，字符集 "ab"（可省，默认小写）
G  = strs(2, n, "01")       # 字符网格：2 行 × n 列
z  = binseq(n, k)           # 0/1 序列：n 位，恰好 k 个 1
iv = intervals(n, 1, 100)   # 区间：n 行，每行 l r
pt = points(n, 1, 10, 1, 10)# 点集：n 行，每行 x y
t  = tree(n)                              # 树：首行 n + n-1 条边，无边权
t2 = tree(n, w=int(1, 10))                # 树 + 整数边权
t3 = tree(n, w=float(0, 1, 4))            # 树 + 浮点边权，精度4
t4 = tree(n, w=int(1,5), val=int(1,9))    # 树 + 节点权值（首行 n，一行 n 个权值，再边）
g  = graph(n, m, 1, 0, w=int(1,10))       # 图：n 顶点 m 边，d=1 有向，c=0 任意连通
g2 = graph(n, m, 1, 0, type="dag")        # 有向无环图
g3 = graph(n, m, 0, 1, type="bipartite")  # 二分图
r  = ring(n)                              # 环：n 条边首尾相连
br = base_ring(n, k)                      # 基环树：n 顶点，环大小 k
# 多组测试数据：group(次数): 后跟缩进块，块内语句随次数重复（每轮独立随机）
T = int(1, 5)
group(T):
    n = int(1, 10)
    a = ints(n, 1, 9)
```

| 命令 | 参数 | 输出 |
| --- | --- | --- |
| `int` | `lo, hi` | 一行 1 个整数 |
| `float` | `lo, hi, prec?` | 一行 1 个浮点 |
| `ints` / `floats` | `n, lo, hi, prec?` | 一行 n 个元素（一维数组） |
| `matrix` / `matf` | `r, c, lo, hi, prec?` | r 行 × c 列元素（多行数组） |
| `perm` | `n` | 一行 `1..n` 随机排列 |
| `str` | `n, 字符集?` | 一行 n 个字符 |
| `strs` | `r, c, 字符集?` | r 行 × c 列字符 |
| `binseq` | `n, k` | 一行 n 位 0/1，恰好 k 个 1 |
| `intervals` | `n, lo, hi` | n 行，每行 `l r`（l<=r） |
| `points` | `n, xlo, xhi, ylo, yhi` | n 行，每行 `x y` |
| `tree` | `n, w?, val?` | 首行 `n` + n-1 条边 |
| `graph` | `n, m, d, c, w?, type?, val?` | 首行 `n m` + m 条边 |
| `ring` | `n` | 首行 `n` + n 条边（环） |
| `base_ring` | `n, k` | 首行 `n` + n 条边（基环树） |
| `group` | `次数:` | 块内语句重复（缩进块） |

**参数说明**：

- 带 `?` 的是可选参数，省略时使用默认值；其余为必填
- `n`、`m`、`r`、`c`、`k` —— 个数/规模，可写常数、引用或表达式（如 `n`、`2*n`、`int(1,5)`）
- `lo`、`hi` —— 取值范围的下限/上限，可为常数或表达式
- `prec` —— 浮点精度（小数位），默认 `6`，如 `float(0, 1, 4)`
- `字符集` —— 字符串用到的字符集合，如 `"01"`、`".#"`；省略默认小写字母 `a-z`
- `w` —— 边权：`int(lo, hi)` 整数或 `float(lo, hi, prec?)` 浮点；省略则无边权
- `val` —— 节点权值：同 `w` 的写法，输出一行 n 个权值
- `type` —— 图结构：`dag`（有向无环，强制有向）/ `bipartite`（二分图，无向）；
  省略为一般图
- `d` —— 图类型：`1` 有向，`0` 无向
- `c` —— 是否连通：`1` 连通，`0` 任意
- `group` 的 `次数:` 后接**缩进块**，块内语句整体重复；块内可引用块外变量，
  块内变量不泄露到外层；**不支持 group 嵌套**（组内不能再套组）

> 引用规则：只能引用前面定义的名字；数组/字符串/序列/区间/点集不可作为引用源；
> `perm`/`tree`/`graph` 被引用时取其规模值。DSL 无法用图形化下拉表达的表达式
> （如 `rows=2*n`）会以只读“表达式(DSL)：...”选项保留，完整编辑请在 DSL 模式进行。
> `group` 块在图形化中以只读组显示，编辑请回 DSL。

## 运行

要求：Python 3.8+（仅标准库）。使用 C++ 模式时需 `g++` 在 PATH 中
（可在“编译设置”里改成 `clang++` 等其它编译器）。

```bash
python duipai.py
```

Windows 打包版：运行 `build.bat` 生成 `dist/对拍机.exe`（无控制台，双击运行）。
打包产物不入库，见下方「仓库说明」。

> **双击 `build.bat` 无反应？** 这是批处理换行符问题：Windows cmd 无法解析 LF 换行的
> `.bat`。用 `git clone` 获取不会有此问题（`.gitattributes` 已固定 CRLF）；若用网页
> "Download ZIP"，先用记事本打开 `build.bat` → "文件 → 另存为"，编码选 UTF-8、
> 换行选 CRLF（或 Windows (CRLF)）再运行，或直接用 `python duipai.py`。

## 使用步骤

1. **填程序**：正解/暴力各填运行命令（如 `python3 ./sol.py`）或切到“C++ 源码”填 `.cpp`。
2. **配置生成器**：
   - 内置：点“+ 整数变量”等添加；数组“行数/每行长度”、树/图“n/m”的来源可设为
     “随机范围”或“引用前面变量”。
   - 外置：选“外置生成器”，填生成程序命令（或 .cpp），种子以 `--seed` 传递。
3. **预览与试运行**：点“预览生成示例”查看样例；点某行的“试运行”单独跑一个程序。
4. **开始对拍**：设置组数、超时、种子后点“开始对拍”；需要时点“停止”。
5. 出现不一致时，到 `./fail/` 目录查看对应 `fail_<编号>.in` 及双方输出。

## 技术说明

- **线程安全**：对拍主循环在独立后台线程运行，只访问纯 Python 数据与 subprocess；
  所有 UI 更新（日志、状态栏、试运行输出、结束统计）经 `queue.Queue` 回传主线程轮询处理，
  后台线程不接触任何 Tcl/Tk 接口。
- **无终端**：所有子进程（正解/暴力/生成器/编译器）在 Windows 下均带
  `CREATE_NO_WINDOW`，不会闪现控制台窗口。
- **C++ 编译**：`<编译器> <编译参数> <源码> -o <临时目录>/<name>.exe`，
  以源码目录为 cwd（相对 include 有效），编译超时 60s，失败则输出 stderr 并停止。
- **UI 风格**：自适应原生主题（Windows vista / macOS aqua / Linux clam），
  浅灰蓝背景 + 蓝色强调，默认控件外观（朴素简洁）。
- **状态持久化**：区块折叠状态保存在程序目录下的 `duipai_state.json`，下次启动自动恢复。

## 架构与数据流

- **线程模型**：`Application`（主线程）负责 UI 构建与事件循环；对拍主循环（`_run_loop`）
  与试运行（`_tryout_worker`）在独立后台线程执行，只访问纯 Python 数据与 subprocess。
  所有 UI 更新（日志、状态栏、试运行输出、结束统计）经 `queue.Queue` 投递，
  由主线程 `after` 轮询（`_poll_queue`）统一回写——后台线程不接触任何 Tcl/Tk 接口。
- **内置数据生成**：主线程 `_snapshot_vars` 把变量列表转成纯 Python 配置，
  后台线程 `_generate_builtin` 逐项生成，维护 `produced[i]`（每项生成的行）与
  `ref_vals[i]`（可引用数值），保证“引用前面变量”取值正确。
- **C++ 编译**：`_compile_cpp`（`g++ <参数> <源码> -o <临时目录>/<name>.exe`，
  cwd=源码目录、`CREATE_NO_WINDOW`、超时 60s）→ `_prepare_program` 统一准备程序，
  对拍与试运行共用同一路径。
- **滚动**：`_wheel_units`（像素换算）→ `_scroll_units`（小数累积 + 整像素滚动 +
  边界钳制）；内层自滚动区域到边界时由 `_on_window_wheel` 接管（滚动链），
  未到边界时交还内层，杜绝双重滚动。

## 常见问题（FAQ）

- **编译失败 / 找不到 g++**：确认 `g++` 在 PATH 中；或到“编译设置”把编译器改为
  `clang++` 等，并检查“编译参数”。
- **对拍很快结束且无输出**：多为程序命令写错、超时太短，或生成器配置不合法（如
  `m` 超出上限、连通图 `m<n-1`）；日志会给出具体原因。
- **试运行一直“正在运行”**：C++ 首次编译可能耗时数秒，属正常；若持续无结果，
  试运行区会显示错误信息（不会静默卡死）。
- **滚轮在列表/日志上没反应**：那是正常滚动链——内层可滚时由它自己滚，
  到边界后整窗会接替；也可直接点击区块标题折叠，减少整窗高度。
- **如何恢复默认布局**：删除程序目录下的 `duipai_state.json` 即可（折叠状态重置）。
- **想直接用已编译的程序**：模式选“运行命令”，填 `./sol` 或 `./sol.exe` 即可，
  无需源码。
